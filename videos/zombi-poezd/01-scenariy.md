# Что если · «Зомби-апокалипсис в поезде зимой»

**Настроение:** страшное, напряжённое.
**Подача:** тише и медленнее, длинные паузы перед развязкой, ключевое слово — отдельно, на выдохе. Теги: `[quiet]`, `[hushed]`, `[slowly]`, `[tense]`, `[whispering]`, `[long pause]`.
**Длина:** ~70 секунд, ~170 слов.
**Голос:** Pavel, `VlCYpQzyafIQIhmvxR2w`, модель `eleven_v4`.
**Стиль (по просьбе автора):** обстановка — 3D (three.js: мультяшная заливка в 3 тона + тёмный контур `#3b2a22`), персонажи — 2D из `parts.tsx` (`Char`). Ночная палитра, тусклые лампы. Зомби мультяшные, без крови. Код: `videos/dvazhdy/src/zombie/`, превью: `npx remotion still ZombiePreview out.png --frame=30 --gl=angle`.

**Обозначения:** `/` — короткая пауза, `//` — пауза, `///` — длинная пауза, **жирный** — ударное слово.

---

### 1. Крючок · 0:00
**Кадр:** заснеженная тайга ночью, по ней ползёт поезд с жёлтыми окошками. Падает снег.
*(тихо, доверительно)*
Представь: / ты едешь в поезде. / Зимой. / За окном / минус **тридцать**. //
И в эту ночь начинается… /// **зомби-апокалипсис**.

### 2. Остановка · 0:08
**Кадр:** плацкарт, герой («ты» — пассажир в шапке с помпоном и красном шарфе) открывает глаза на верхней полке. Лампа мигает. Чай в подстаканнике дрожит, потом замирает.
*(медленно)*
Ты просыпаешься в **три** часа ночи. / Поезд стоит. / Посреди **тайги**. //
Свет мигает. / Из соседнего вагона — **крик**. /// Потом — тишина.

### 3. Проводница · 0:18
**Кадр:** длинный проход, в конце — силуэт проводницы. Идёт рывками, голова набок.
*(шёпотом)*
По проходу идёт проводница. / Медленно. / Голова — набок. ///
Она / не **моргает**.

### 4. Правило первое · 0:25
**Кадр:** вид из окна — чёрный лес, сугробы по пояс. Цифры на экране: «−30°», «80 км до станции».
*(напряжённо, но ровно)*
Первое правило: / **не беги** наружу. / До станции — восемьдесят километров. //
Снаружи тебя убьют не зомби. /// **Холод**.

### 5. Купе · 0:34
**Кадр:** герой ныряет в пустое купе, щёлкает замком, подпирает ручку чемоданом. Ручка дёргается.
*(тише, быстрее)*
Второе: / **купе**. / Замок. / Чемодан под ручку. //
Стук. /// Ещё стук.

### 6. Догадка · 0:41
**Кадр:** герой у окна. Снаружи у вагона стоят несколько зомби — по колено в снегу, покрытые инеем, неподвижны.
*(медленно, с осознанием)*
И тут ты видишь: / те, кто выбрался из поезда, / стоят в снегу / и **не двигаются**. //
Они **замёрзли**.

### 7. План · 0:49
**Кадр:** герой надевает три куртки, обматывается одеялами. Открывает окно, потом двери тамбура. В вагон летит снег, всё покрывается инеем.
*(напряжённо, по нарастающей)*
Ты собираешь одеяла / со всего вагона. / Надеваешь всё, что есть. //
И открываешь двери. / **Все**. //
Вагон остывает. / Шаги в коридоре / всё медленнее… / медленнее… ///
*(шёпотом)*
И стихают.

### 8. Финал · 1:02
**Кадр:** рассвет, герой в коконе из одеял, изо рта пар. Вдали — огни встречного поезда. Наезд камеры: в его окнах темно.
*(тихо, с облегчением, потом снова тревожно)*
К утру ты **жив**. // Вдалеке — гудок. / Идёт встречный поезд. ///
*(шёпотом, на выдохе)*
Вот только / в его окнах… /// не горит **свет**.

*(на экране вопрос: «А что бы сделал ты?», голос молчит)*

## Плашки
Имён нет — герой это «ты». Вместо плашек — карточки правил в том же стиле (кремовая карточка, красная полоса): «Правило 1: не выходи», «Правило 2: запрись», «Правило 3: холод — союзник».
