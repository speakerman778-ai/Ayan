# Вселенная Шнурка · «Овощ», 3 серия — «Вердура»

**Стиль:** 3D мир + 2D герои. **Голос:** Pavel, eleven_v4. **Длина:** ~1 мин 40 с. **От первого лица.** Текст — `ep08-ovoshch-3-voice.txt`.

1. **Итог голосования.** Экран выбора из 2 серии, «2 — в Барселону» побеждает.
2. **Прощание.** Ночь, фонарь, Шнурок и Палыч перекидывают мяч до рассвета. Палыч: «Лети, Овощ. Только не забывай, где тебя сделали».
3. **Испания.** Самолёт → «Ла Масия»: солнце, пальмы, сине-гранатовая форма (без эмблемы клуба).
4. **Всё повторяется.** Тренировка: Шнурку не дают пас, смеются. Марко — новый персонаж (придуманный, смуглый, кудрявый, с повязкой на волосах) — показывает пальцем: «Вердура!» Над Шнурком снова всплывает морковка, с испанским флажком.
5. **Скамейка.** Шнурок один на скамейке под южным солнцем.
6. **Ночное поле академии.** Пальмы в темноте, один фонарь, Шнурок бьёт. С другого конца поля — звук ударов.
7. **Марко.** Он тоже тренируется ночью, один. «Ты тоже?» — монтаж: они тренируются вдвоём, дают пасы, смеются.
8. **Финал.** «Барселона — Мадрид», полный стадион, 0 : 0, последняя минута. Мяч у Шнурка. Стоп-кадр: слева он сам и трудный угол ворот, справа открытый Марко.
9. **Выбор.** «1 — бить самому» / «2 — пас Марко». «Что бы выбрал ты?»
