# Вселенная Шнурка · «Овощ», 3 серия — «Вердура»

**Стиль:** 3D мир + 2D герои. **Голос:** Pavel, eleven_v4. **Длина:** ~2 мин. **От первого лица.** Текст — `ep08-ovoshch-3-voice.txt`.

1. **Голосование + прощание.** «2 — в Барселону» побеждает. Ночь, фонарь, Шнурок и Палыч до рассвета; «Лети, Овощ».
2. **«Ла Масия».** Солнце, пальмы, сине-гранатовая форма (без эмблемы клуба).
3. **Вердура.** Пас не дают, смеются. Марко (придуманный: смуглый, кудрявый, с повязкой) — «Вердура!», над Шнурком морковка с испанским флажком.
4. **Условие тренера.** Тренер академии (придуманный) ставит их рядом: «В основной состав — только один. Завтра дуэль, пять пенальти каждому». Табличка «1 место».
5. **Раздевалка вечером.** Марко один, плачет, говорит по телефону маме: «Если меня не возьмут — нам нечем будет платить за дом». Шнурок замирает в дверях.
6. **Дуэль.** Пустой стадион на закате, только тренер. Счётчик пенальти, удары по очереди: 1:1 … 4:4. Последний удар Марко — мимо.
7. **Последний удар Шнурка.** Мяч на точке. Крупно: мяч → Марко смотрит в землю → тренер. Стук сердца.
8. **Что будет, если «1».** Картинка-мечта: Шнурок в основном составе, Палыч дома смотрит матч по телевизору и улыбается. Затем — Марко с сумкой у ворот академии, мама с коробками у дома.
9. **Что будет, если «2».** Мяч мимо, тренер хмурится («переигровка»), над Шнурком — знак вопроса и билет домой. Затем — Марко поднимает голову, у него снова шанс.
10. **Выбор.** Экран пополам: «1 — забить и забрать место» / «2 — пробить мимо, дать шанс Марко». «Что бы выбрал ты?»
