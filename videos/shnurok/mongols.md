# Монголы и Чингисхан (отдельный мультик для урока, без Шнурка, 2D)

**Стиль:** плоский 2D канала. **Голос:** Pavel, eleven_v4. **Длина:** ~1 мин 50 с. **Подача:** историческая, напряжённая в сценах войны.
Текст озвучки — `mongols-voice.txt`.

**Проверка фактов:**
- Темучин родился ок. 1162 г. (даты в источниках 1155–1167); отца Есугея отравили татары. ✔
- 1206 — курултай на реке Онон, Темучин провозглашён Чингисханом. ✔
- Яса — свод законов; десятичная система войска (десятки, сотни, тысячи, тумены); ямская служба. ✔
- 1218 — Отрарская катастрофа: наместник Каир-хан (Инальчук) перебил монгольский караван → повод для войны. ✔
- 1219 — осада Отрара, около 5–6 месяцев, город пал в начале 1220; затем Сыгнак, Бухара, Самарканд. ✔
- 1227 — смерть Чингисхана; Улус Джучи (позже Золотая Орда) включал большую часть Казахстана. ✔
- Монгольская империя — крупнейшая сплошная (непрерывная) империя в истории. ✔
