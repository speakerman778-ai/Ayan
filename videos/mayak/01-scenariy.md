# Маяк · Серия 1 — «Помощник смотрителя»

**Настроение:** доброе, светлое (немного напряжения в середине, но без мрака).
**Подача:** живой голос, как другу рассказываешь. Теги — только `[warmly]`, `[smiling]`, `[pause]`.
**Длина:** ~65 секунд, ~160 слов.
**Голос:** Pavel, `VlCYpQzyafIQIhmvxR2w`, модель `eleven_v4`.

**Обозначения:** `/` — короткая пауза, `//` — пауза, **жирный** — ударное слово, *(курсив)* — подсказка подачи.

### 1. Крючок · 0:00
**Кадр:** ночь, маяк на зелёном утёсе, крутится луч. Крупно — тёмное окошко домика.
*(загадочно, но с улыбкой)*
Этот маяк каждую ночь зажигает **дед Савелий**. // А однажды / его зажёг… // **кот**.

### 2. Каждый вечер · 0:06
**Кадр:** винтовая лестница, Савелий в жёлтом дождевике поднимается, Компас трусит следом. Наверху — большой медный рычаг.
*(ровно, по-домашнему)*
Каждый вечер ровно в **девять** / Савелий поднимается на сто двенадцать ступенек / и тянет большой медный **рычаг**. //
А кот **Компас** сидит рядом / и смотрит. / Каждый раз.

### 3. Простуда · 0:17
**Кадр:** кухня, Савелий в шарфе, градусник, чай с малиной (пар), кот на одеяле. Часы с маятником.
*(сочувственно, чуть медленнее)*
Но этой осенью дед **простыл**. / Чай с малиной, / шарф, / одеяло. //
Прилёг «на минутку» — / и **уснул**.

### 4. Туман · 0:25
**Кадр:** море в тумане, маленькая лодка с фонариком качается на волнах. Маяк — тёмный.
*(тише, с лёгкой тревогой)*
Девять часов. / На море — **туман**. //
Где-то там рыбак **Тимофей** ищет дорогу домой. / А маяк… / не горит.

### 5. Компас · 0:33
**Кадр:** кот смотрит на часы → на спящего деда → на лестницу. Бежит наверх (быстрая смена ступенек). Прыгает на рычаг — не поддаётся. Отходит, разбегается, прыгает всем весом.
*(живее, с азартом)*
Компас смотрит на часы. / На деда. / На лестницу. //
Сто двенадцать ступенек. / Прыжок на рычаг — / не поддаётся. //
*(с улыбкой)*
Ещё раз — / всем весом. / А весит Компас / **немало**. //
**Щёлк!**

### 6. Свет · 0:45
**Кадр:** лампа вспыхивает, луч прорезает туман, лодка поворачивает к берегу.
*(тепло, с облегчением)*
Луч прорезает туман, / и лодка Тимофея / поворачивает к **берегу**.

### 7. Утро · 0:50
**Кадр:** утро, солнце. Стук в дверь: на пороге рыбак с ведром рыбы. Савелий в пижаме удивлённо смотрит на кота. Кот облизывается.
*(весело, с удивлением)*
Утром — стук в дверь. / Тимофей с ведром рыбы: / «Спасибо, Савелий, **выручил**!» //
А дед смотрит на кота. / И не понимает, / за что его благодарят.

### 8. Финал · 0:58
**Кадр:** Компас ест рыбу из миски. Камера на дверь маяка: две таблички — «Смотритель» и маленькая «Помощник смотрителя» с отпечатком лапы.
*(тепло, с улыбкой)*
Рыбу дед отдал тому, / кто её **заслужил**. //
А на двери маяка / теперь **две** таблички. ///
*(на экране вопрос: «А у вашего кота есть работа?», голос молчит)*
