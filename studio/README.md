# Мультмаяк: сайт студии мультиков и роликов на заказ

Лендинг, который продаёт ролики на заказ. Сборка не нужна: достаточно открыть `index.html`.

## Чтобы сайт начал принимать заявки

1. Контакты лежат в `config.js`. Там уже вписан WhatsApp, заявки с формы приходят в него с готовым текстом.
2. Цены меняются в `index.html`, раздел «Цены».
3. Плашка «цена для первых клиентов»: в `config.js` число `firstClientsLeft`. После каждого заказа уменьшайте его на 1, а на 0 плашка исчезнет сама.

## Как выложить в интернет бесплатно

GitHub → репозиторий → Settings → Pages → Branch: `main`, папка `/ (root)`.
Сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/studio/`.
Свой домен (например, mayak-studio.kz) подключается там же.

## Откуда брать клиентов

- В описании TikTok, Reels и YouTube-канала: «Делаю такие мультики на заказ», со ссылкой на сайт.
- Объявление на OLX.kz (раздел «Услуги»), Kwork и FL.ru со ссылкой на портфолио.
- Пишите напрямую кофейням, школам и салонам в вашем городе и сразу присылайте бесплатный пробный кадр с их маскотом.

## Чтобы сайт находился в Google по слову «Мультмаяк»

1. Включите GitHub Pages (см. выше). Страницы на claude.ai Google не индексирует.
2. Откройте search.google.com/search-console, нажмите «Добавить ресурс» → «Префикс URL»
   и вставьте `https://speakerman778-ai.github.io/Ayan/studio/`.
3. Подтвердите владение способом «HTML-тег»: пришлите мне этот тег, я вставлю его в `index.html`.
4. В разделе «Файлы Sitemap» добавьте `sitemap.xml`, затем в «Проверке URL» нажмите «Запросить индексирование».
5. Через 3–14 дней сайт начнёт выходить по запросу «Мультмаяк».
   Ускоряет: ссылка на сайт в TikTok, Instagram, OLX.kz и карточка в 2GIS с названием «Мультмаяк».
