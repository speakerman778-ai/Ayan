# Студия «Маяк»: сайт для заказа мультиков и роликов

Лендинг, который продаёт ролики на заказ. Сборка не нужна: достаточно открыть `index.html`.

## Чтобы сайт начал принимать заявки

1. Контакты лежат в `config.js`. Там уже вписан WhatsApp, заявки с формы приходят в него с готовым текстом.
2. Цены меняются в `index.html`, раздел «Цены».

## Как выложить в интернет бесплатно

GitHub → репозиторий → Settings → Pages → Branch: `main`, папка `/ (root)`.
Сайт откроется по адресу `https://<ник>.github.io/<репозиторий>/studio/`.
Свой домен (например, mayak-studio.kz) подключается там же.

## Откуда брать клиентов

- В описании TikTok, Reels и YouTube-канала: «Делаю такие мультики на заказ», со ссылкой на сайт.
- Объявление на OLX.kz (раздел «Услуги»), Kwork и FL.ru со ссылкой на портфолио.
- Пишите напрямую кофейням, школам и салонам в вашем городе и сразу присылайте бесплатный пробный кадр с их маскотом.
