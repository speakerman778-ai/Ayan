# Roblox FPS Booster

Простой ускоритель FPS для Roblox на Windows 10/11. Не чит: игру не взламывает и не внедряется в неё, поэтому бана за него нет. Меняет только настройки Windows и официальный файл настроек Roblox (`ClientAppSettings.json`, только разрешённые Roblox флаги).

## Как запустить

1. Скачай папку `roblox-fps-booster`.
2. Закрой Roblox.
3. Дважды кликни **`Start.bat`**.
4. Выбери **1 — ВСЁ СРАЗУ**.
5. Зайди в игру: `Esc → Settings` → **Maximum Frame Rate** на максимум, **Graphics Quality** вручную 1–3.

Если Windows пишет «Защитник Windows предотвратил запуск» — «Подробнее» → «Выполнить в любом случае» (скрипт открытый, его можно прочитать в `FPSBooster.ps1`).

## Что делает

| Пункт | Что меняет |
|---|---|
| Графика: минимум | без сглаживания, низкие текстуры, без травы, серое небо, упрощённые детали, DirectX 11 |
| Графика: средне | только без сглаживания и травы, остальное как в игре |
| Ускорить Windows | схема питания «Высокая производительность», Roblox на мощную видеокарту (ноутбуки), выкл. фоновая запись Xbox Game Bar, вкл. игровой режим |
| Очистить кэш | кэш и логи Roblox, временные файлы Windows |
| Высокий приоритет | Roblox получает больше процессора, пока открыт |
| Откатить | возвращает всё как было |

Работает с обычным Roblox, Bloxstrap и Fishstrap. После обновления Roblox графику нужно применить заново (пункт 2 или 1).
