# Быстрый рендер роликов

Контейнер: 4 ядра, 15 ГБ памяти, без видеокарты. WebGL считается на процессоре (`--gl=angle`), поэтому 3D-сцены — самая медленная часть. Полный ролик на 75 с (2300 кадров) в финальном качестве рендерится ~35 минут. Почти всё время уходит на тени и сглаживание three.js.

## Порядок: сначала дёшево, в конце дорого

1. **Проверка кадра — только `still`, не видео.** Один кадр ≈ 15 с (почти всё — сборка проекта).
   ```bash
   npx remotion still ZombieEp01 out/f.png --frame=600 --gl=angle
   ```
   Несколько моментов сразу — собрать в один лист (Pillow) и смотреть лист, а не каждый файл:
   ```bash
   for s in 4 16 28 44 61; do npx remotion still ZombieEp01 out/zs/$s.png --frame=$((s*30)) --gl=angle; done
   ```
2. **Правка одной сцены — рендерить только её кадры**, не весь ролик:
   ```bash
   npx remotion render ZombieEp01 out/part.mp4 --gl=angle --frames=1200-1430
   ```
3. **Проверка таймингов/анимации целиком — черновик** (без теней и сглаживания, вдвое меньше размер):
   ```bash
   npx remotion render ZombieEp01 out/draft.mp4 --gl=angle --concurrency=3 --scale=0.5 --props='{"draft":true}'
   ```
   В компоненте ролика флаг читается так (уже сделано в `src/zombie/ZombieEp01.tsx`, в новых сериях делать так же):
   ```tsx
   const DRAFT = Boolean((getInputProps() as {draft?: boolean}).draft);
   <ThreeCanvas shadows={!DRAFT} gl={{antialias: !DRAFT}} ... />
   ```
4. **Финал — один раз**, когда всё проверено:
   ```bash
   npx remotion render ZombieEp01 out/zombie-ep01.mp4 --gl=angle --concurrency=3
   ```
   Запускать в фоне (`run_in_background`), не ждать в переднем плане.

## Настройки

- `--concurrency=3` на 4 ядрах (одно ядро оставить браузеру и кодеку). Другие значения пока не сравнивались — если проверишь, допиши сюда результат.
- `--gl=angle` обязателен для three.js, без него 3D не рисуется.
- Не ставить `--image-format=png` для видео: по умолчанию jpeg, он быстрее.

## Как делать сцены, чтобы они рендерились быстрее

- Тени (`castShadow`) — только у одного главного источника света в сцене; у остальных ламп выключены. Размер карты теней 1024, на улице — 2048, не больше.
- Снег, листья и другие частицы — 2D-кругами в SVG поверх 3D, а не тысячами 3D-сфер. 3D-снежинок — не больше ~120 на сцену.
- Геометрию и материалы кэшировать (`clay()` и `rbox()` в `src/zombie/Train3D.tsx`), не создавать новые на каждом кадре.
- Лес/толпа — до ~100 объектов; дальние деревья всё равно в тумане.
- Звук собирать отдельно скриптом (`build_*_audio.py`), это секунды — не перерендеривать видео ради звука: склеить готовое видео с новым `mix.wav` через ffmpeg:
  ```bash
  ffmpeg -i out/video.mp4 -i public/zombie/ep01-mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -shortest out/final.mp4
  ```
