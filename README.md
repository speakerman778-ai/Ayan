# 🎬 Моё кино

Личный каталог фильмов и сериалов.

- Поиск по названию (русскому и оригинальному) и году
- Вкладки: Фильмы, Сериалы, «Хочу посмотреть», «Смотрю», «Просмотрено», «Любимое»
- Фильтр по жанру и сортировка по рейтингу, году, названию
- Кнопка «🎲 Что посмотреть?» выбирает случайный непросмотренный тайтл
- Можно добавлять свои фильмы и сериалы
- В карточке есть ссылки «Где смотреть» (JustWatch), трейлер, Кинопоиск и IMDb

Списки и добавленные тайтлы хранятся в браузере (localStorage).

## Вся база фильмов и сериалов (TMDB)

Без ключа работает встроенный каталог из `data.js`. Чтобы искать по всей базе
[TMDB](https://www.themoviedb.org) (постеры, описания на русском, актёры, трейлеры,
где смотреть в России):

1. Зарегистрируйтесь на themoviedb.org.
2. Откройте Настройки → API и получите бесплатный ключ.
3. На сайте нажмите ⚙ и вставьте «Ключ API» или «Токен доступа к API».

Ключ сохраняется только в вашем браузере. Если TMDB не открывается
(в некоторых странах он заблокирован), сайт автоматически покажет встроенный каталог.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны.

Стартовый каталог лежит в `data.js`, туда можно дописывать новые тайтлы.
